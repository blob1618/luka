# Render no puede consultar los ZIP oficiales

- El despliegue [347d212](https://github.com/blob1618/luka/commit/347d212664829817446bd54c62531e092a0212d0) quedó Live el 20/11/2026. El bootstrap comenzó a las 11:43:45 AR.
- En los [logs de Render](https://dashboard.render.com/web/srv-d9656eeq1p3s73bgl210/logs?t=app&r=1h&q=sepa), el catálogo de metadatos y los siete recursos ZIP semanales oficiales respondieron `403 Forbidden` desde ese servicio. A las 11:43:53 AR terminó con `ValueError: No se pudo consultar ningún ZIP semanal oficial de SEPA`.
- En la máquina local, el catálogo y los ZIP sí habían respondido 200. Esto prueba una diferencia de acceso por entorno; no prueba la causa exacta del bloqueo.
- Al cierre de esta observación, la tabla productiva seguía sin snapshot publicado. La solución propuesta es publicar una copia verificable desde GitHub Actions y hacer que Render la consuma sólo si es reciente. La ejecución del workflow, la carga productiva y WhatsApp real permanecen pendientes.
